## Notes

- The backend suite uses `monkeypatch` fixtures and does NOT hit PostgreSQL; AC-3 live happy-path is exercised at the E2E layer against the real seeded DB row (`admin@example.com` / `password123`).
- All E2E specs live in `admin/e2e/login.spec.ts` and run via `npm run test:e2e` using the committed `playwright.config.ts` (headed, slowMo=2000, Chromium only).
- Fix agents: label backend failures `backend` and frontend failures `frontend` when filing issues. One failed case → one GitHub issue.
